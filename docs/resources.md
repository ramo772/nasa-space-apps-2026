## Purpose

One place where teammates find links to workshop and reference material instead of digging through chat history. This page is an index, not a copy: each workshop keeps its own takeaways in `docs/workshops/`, verified NASA datasets stay in `docs/research/source-register.md`, and this page only points to them. Listing something here is **not** a team decision and does not adopt a tool, dataset or design.

## How to use this page and its rules

- **Links only.** Do not commit slide decks, PDFs, zips, saved web pages, QR images or screenshots from workshops; the repository rules forbid copyrighted assets without permission. If the team wants offline copies, ask the instructor first and keep them in the team's shared drive, not in the repository.
- Each link gives a name, what it is for, and a "checked on" date. Only what was actually opened is marked verified.
- No keys, tokens, passwords, or personal contact details of instructors or teammates.
- This page is not a decision log: listing a tool or idea here does not mean the team chose it.
- Add new links in a small PR and keep the workshop table sorted by date.
- The team's own files (Figma links, PDFs, presentations) are **links only** here. If the TL wants team-made files stored in the repository, they belong under `assets/` and follow its README (source, licence and creator explained in the PR), decided in a separate PR.

## NASA data and APIs — quick pointers

- Verified datasets, coverage, units and licences live **only** in [the source register](research/source-register.md). Nothing is duplicated here.
- [NASA POWER API docs](https://power.larc.nasa.gov/docs/services/api/) — checked 2026-11-03.
- [NASA POWER parameter dictionary](https://power.larc.nasa.gov/docs/tutorials/parameters/) — checked 2026-11-03.
- [JPL Sentry API](https://ssd-api.jpl.nasa.gov/doc/sentry.html) — checked 2026-11-03.
- Named in the API workshop with no URL recorded; official pages found and checked 2026-11-03:
  - [EPIC](https://epic.gsfc.nasa.gov/) — DSCOVR Earth imagery.
  - [DONKI](https://ccmc.gsfc.nasa.gov/tools/DONKI/) — space-weather notifications and database.
  - [NeoWs](https://api.nasa.gov/) — documented on the NASA Open APIs portal (no separate page recorded).
  - [APOD](https://apod.nasa.gov/apod/astropix.html) — resolves to NASA Science.
  - [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/).
  - [NASA Earthdata](https://www.earthdata.nasa.gov/) and [NASA Worldview](https://worldview.earthdata.nasa.gov/).
  - [USGS earthquake API](https://earthquake.usgs.gov/fdsnws/event/1/).
- **Keys:** a free NASA key is fine to use in a web page; any paid key (for example an AI provider key) must never be in a web page or public repository.
