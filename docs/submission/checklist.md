# NASA project submission / demo checklist

Verify the current **2026 official** criteria and local Cairo instructions before the event.

- [ ] Every team member registered and associated with the correct official team/local event.
- [ ] Official challenge selected and solution aligned to challenge statement.
- [ ] Credible NASA/partner data use explained, with all source credits/links.
- [ ] A single end-to-end demo works from a clean browser/device.
- [ ] Public source or code access ready if required by current rules (no secrets exposed).
- [ ] Screenshots/video and README explain challenge, impact, method, limitations and innovation.
- [ ] Pitch has understandable story and evidence; all six know the demo flow.
- [ ] Project submission page completed and successfully submitted before the local deadline.
- [ ] Backup video/screenshots and fallback demo are available if internet or API fails.
