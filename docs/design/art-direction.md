# Art direction and asset provenance

**Status:** Identity v1 selected; production art remains subject to ticket-level review.
**Tool preference:** ArtCraft for exploration and optional illustration/3D visual assets; **no mandatory Figma workflow**.

## One design identity
- Approved color/typography/spacing decisions: `docs/design/identity.md` and `design/tokens.json`.
- Approved character, environment and key-art references: `assets/identity/`.
- Character invariants: `docs/design/characters.md`.
- Sound and comedy direction: `docs/design/audio-and-comedy.md`.
- Source assets: `assets/artcraft/` (only approved, licensed assets; save prompt/creator/license notes in each asset's PR).
- Code UI is built from shared tokens and reusable components once implementation is authorized (DEC-006 in `docs/technical/decisions.md`).
- No AI agent may invent a new visual palette or copy unofficial NASA marks for a screen.
- If the final challenge needs scientific charts, clarity and verifiable data provenance outrank visual effects.
