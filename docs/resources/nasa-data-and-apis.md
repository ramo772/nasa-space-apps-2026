# NASA data and APIs

**Status:** Draft  
**Type:** reference  
**Back to index:** [Team resources](README.md)

Quick pointers to NASA API and dataset documentation. Verified datasets, coverage, units and licences live **only** in [the source register](../research/source-register.md); nothing is duplicated here.

| Name | Link | What it is for |
|---|---|---|
| Source register | [research/source-register.md](../research/source-register.md) | The only place where verified datasets, coverage, units and licences are recorded |
| NASA POWER API docs | <https://power.larc.nasa.gov/docs/services/api/> | POWER data services and API — checked 2026-11-03 |
| NASA POWER parameter dictionary | <https://power.larc.nasa.gov/docs/tutorials/parameters/> | POWER parameter definitions — checked 2026-11-03 |
| JPL Sentry API | <https://ssd-api.jpl.nasa.gov/doc/sentry.html> | Near-Earth object impact-risk data — checked 2026-11-03 |
| EPIC | <https://epic.gsfc.nasa.gov/> | DSCOVR Earth imagery — checked 2026-11-03 |
| DONKI | <https://ccmc.gsfc.nasa.gov/tools/DONKI/> | Space-weather notifications and database — checked 2026-11-03 |
| NeoWs | <https://api.nasa.gov/> | Near-Earth object feed, documented on the NASA Open APIs portal (no separate page recorded) — checked 2026-11-03 |
| APOD | <https://apod.nasa.gov/apod/astropix.html> | Astronomy picture of the day; resolves to NASA Science — checked 2026-11-03 |
| NASA Exoplanet Archive | <https://exoplanetarchive.ipac.caltech.edu/> | Exoplanet and host-star data — checked 2026-11-03 |
| NASA Earthdata | <https://www.earthdata.nasa.gov/> | Gateway to NASA Earth observation data — checked 2026-11-03 |
| NASA Worldview | <https://worldview.earthdata.nasa.gov/> | Browse near-real-time Earth imagery — checked 2026-11-03 |
| USGS earthquake API | <https://earthquake.usgs.gov/fdsnws/event/1/> | Earthquake catalog data — checked 2026-11-03 |

A free NASA key is fine to use in a web page; any paid key (for example an AI provider key) must never be in a web page or public repository.
