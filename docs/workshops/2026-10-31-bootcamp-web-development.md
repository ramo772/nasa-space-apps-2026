## Purpose
Record one teammate's takeaways from the bootcamp's web-development workshop so the team can
evaluate them when a challenge is selected. **Nothing here is a team decision or a verified
rule.** Items 7-9 look like event or organizer requirements but carry no citation in the
source notes; confirm them against the official 2026 rules before relying on any of them.

## Content

### Suggested approach and stack
1. **Keep the project simple.** Plain HTML, CSS and JavaScript was the example given.
   This does not supersede `docs/technical/architecture.md`, where the stack is still
   "TBD at kickoff based on challenge, team abilities, and actual datasets".
2. **Create a repository** for the project.
3. **Deploy through automated hosting.** GitHub Actions was mentioned in the workshop; the
   note's author states a personal preference for Cloudflare. Neither is evaluated or chosen.
4. **3D models in the browser:** the presenter used <https://modelviewer.dev/> — the
   `<model-viewer>` web component for displaying 3D models on a page. Our team has not
   evaluated it, and no challenge need for 3D has been established.
5. **Vibe coding or an AI agent** was presented as an acceptable way to build.
6. **"Use ChatGPT Go"** — recorded verbatim; the intended meaning is unclear. No tool has
   been chosen or paid for by this team, and no paid service may be adopted without TL
   consent (`docs/team/working-agreement.md`).

### Stated submission and compliance points — unverified
7. The project description **can** state that AI was used, and **should** explain *how* it
   was used. Our `docs/submission/checklist.md` currently has no AI-disclosure line.
8. **Do not place the NASA logo on any AI-generated image or video.** Adjacent existing
   guidance: `docs/design/art-direction.md` already forbids copying unofficial NASA marks,
   and `docs/design/identity.md` forbids claiming NASA affiliation or assuming logo rights.
9. The repository **should not be private**, and shared data should not be private.
   This contradicts `docs/team/github-setup.md` ("Keep the remote repository private
   initially") and `README.md` step 2 ("Create a **private** GitHub repo"). As of
   2026-10-31 the live repository is in fact **public**.
