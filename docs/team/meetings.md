# Meetings and note-taking for six-person team

## Rhythm
- Before the event: one kickoff (45–60 min), then a short weekly alignment (25–30 min) as needed.
- During the event: short checkpoints and integration demos; no meeting for what a GitHub comment can resolve.

## Before the meeting
- Send **calendar invite** with agenda, source links and expected decisions; appoint facilitator and rotating note-taker.
- If using auto-transcription, obtain attendee consent; verify mixed Arabic/English names and technical terms.

## Immediately after
1. Create minutes via `meeting-notes` using `docs/team/meeting-notes/TEMPLATE.md`.
2. TL distinguishes **confirmed decisions** from **proposals** and approves the draft.
3. Run `process-meeting` to review changes, then `sync-docs` → `create-issues` → `sync-board` as needed.
4. Post a short summary with links in chat. Avoid duplicating approved content into Notion.
