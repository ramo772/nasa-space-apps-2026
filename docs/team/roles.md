| 2: Research / data | Challenge interpretation, NASA datasets, validation, citations | Demo narrative |

| 4: Frontend | UI implementation, data states, responsiveness | Integration |
| 5: Backend / integration | API/contracts, data transformation, deployment | QA |
| 6: AI / QA / pitch | Model/algorithm if needed, verification, pitch/video | Research |

Adapt to real skills; never force an AI feature. Every P0 ticket has one **assignee**, optional collaborators and one reviewer (not self). The TL coordinates blockers but is not required to write every change.
